☁️ 腾讯云COS 配置教程

💡 前置要求 需要一个腾讯云账号，实名认证后即可免费使用。

第一步：开通 COS 服务

1 登录腾讯云
访问 cloud.tencent.com，使用微信或QQ登录，并进行实名认证。
2 进入对象存储控制台
登录后在控制台搜索 对象存储 或访问：
https://console.cloud.tencent.com/cos5

第二步：创建存储桶

3 点击「创建存储桶」
点击「Bucket列表」，然后点击「创建存储桶」按钮。
4 填写存储桶信息 
名称：wedding-photos-你的名字（如 wedding-photos-lisi）
地域：选择离你最近的地区（如 ap-shanghai 上海）
访问权限：选择「公有读私有写」

第三步：获取配置信息

5 记录存储桶名称
在存储桶列表中复制你的存储桶名称，格式如：
wedding-photos-lisi-1234567890
6 获取地域名称
在存储桶「基本信息」中找到「所属地域」，记住对应的英文缩写：
上海 = ap-shanghai
北京 = ap-beijing
广州 = ap-guangzhou
成都 = ap-chengdu
7 获取 SecretId 和 SecretKey
访问： 访问密钥管理
创建一个密钥或使用已有的密钥，复制 SecretId 和 SecretKey。
⚠️ 重要提示 SecretKey 相当于密码，请勿泄露给他人！

第四步：配置页面

8 填写配置信息
回到照片收集页面，点击 ⚙️ 设置按钮，填写： 
环境 ID：留空（或填存储桶名称）
云存储 Bucket：你的存储桶名称
云存储 Region：你选择的地域代码
使用云开发：☑️ 勾选
9 点击测试连接
点击「测试连接」按钮，确保配置正确后保存设置。

第五步：部署上线

10 部署到 GitHub Pages
1. 创建 GitHub 仓库
2. 上传 index.html 文件
3. 启用 GitHub Pages
4. 获取访问链接分享给宾客
💡 费用说明 腾讯云COS有免费额度：50GB存储空间、10GB/月流量。普通婚礼使用完全足够，超出部分费用很低。

常见问题

Q: 上传的照片在哪里查看？
A: 在腾讯云 COS 控制台的存储桶中，可以查看所有上传的照片。
Q: 宾客能看到其他人的照片吗？
A: 可以看到所有人都上传的照片，形成互动氛围。
Q: 需要给每个宾客配置账号吗？
A: 不需要，宾客直接打开链接即可上传，无需登录。
